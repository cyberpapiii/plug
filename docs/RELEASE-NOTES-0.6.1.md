# Plug 0.6.1

Plug 0.6.1 fixes the one-time handoff that lets the Mac app take ownership of
Plug's background service. On current macOS releases, choosing **Use Plug** no
longer crashes the app while replacing an older command-line-managed daemon.

This release includes the complete 0.6.0 interface redesign: a calm single
sidebar, full-width server list, clearer client and authentication views,
compact setup guidance, and a quieter menu-bar experience.
