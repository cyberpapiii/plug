# Plug 0.7.1

Plug 0.7.1 is the safe installation patch for the unified macOS release.

It fixes a self-verification loop in Plug 0.7.0 that could make the embedded
CLI time out after Plug.app was installed. No configuration, credentials, or
user data are changed.

All Plug 0.7.0 product improvements remain included: one app-owned runtime,
automatic CLI and client repair, signed Sparkle updates, and Linux-only
standalone packages.
