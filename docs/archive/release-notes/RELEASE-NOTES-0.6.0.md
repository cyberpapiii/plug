# Plug 0.6.0

Plug 0.6.0 turns the Mac app from a technical control panel into a calm,
useful home for Plug.

The window now has one clear navigation sidebar and one full-width workspace.
Servers are shown in a readable list instead of a cramped nested split view;
selecting one opens details only when you want them. Clients, activity, and
authentication now share the same visual rhythm, with useful summaries,
honest empty states, and actions placed beside the thing they affect.

The setup prompt is smaller and quieter, connection status lives where it can
be glanced at, and background refreshes no longer make the app appear to
disconnect every few seconds. Destructive server and client actions now ask
before proceeding.

The menu-bar menu is calmer too: it reports overall health and only names
servers that need attention.

This release includes the 0.5.3 local-IPC fixes, so the app both connects to the
daemon correctly and presents its data cleanly.
